// Features

Subtitles that read like
they were made for you

Built into YouTube's own player. No extra app, no account, and your library never leaves your browser.

Sentence-level AI translation

Auto-generated captions cut sentences into fragments. SubScribe first builds a context summary and glossary of names and terms, then translates whole sentences so every subtitle reads naturally — and checks that no line is skipped or merged too far. Works with Gemini, Claude, GPT and more via OpenRouter.

18 languages openrouter

Synced to the millisecond

Timing never comes from the AI. It is taken from the caption data YouTube's player uses, so subtitles appear and disappear exactly when the words are spoken.

ms timing

Bilingual, your style

Show the translation alone or with the original underneath. Choose size, color and background — YouTube's own captions step aside automatically.

Fine-tune the timing

Off by a beat? Nudge subtitles with [ and ] (hold Shift for bigger steps) and reset with \. Works on any keyboard layout.

Export SRT & VTT

Download any translation as a standard subtitle file for your video player, editor or your own uploads.

AI summaries

Bullet points, a paragraph or key takeaways — in the language, tone and length you pick, with timestamps that jump to the moment.

Local library

Transcripts, translations and summaries are saved in your browser with tags, favorites and typo-tolerant search. Back up everything as JSON.

Transparent & resilient

See the exact cost of every translation. Cancel any time — an interrupted translation picks up where it stopped instead of paying twice.

// Get started

Up and running in 3 steps

No build tools, no account with us. Install and translate your first video in a few minutes.

1

Install Tampermonkey

Add the free Tampermonkey extension to Chrome, Edge, Firefox or a browser based on them.

2

Add SubScribe

Click Install — Tampermonkey opens and asks you to confirm. Updates arrive automatically.

3

Add a key, press Translate

Paste an OpenRouter API key in settings, open any video with captions and press Translate.

// FAQ

Common questions

Your library lives only in your browser (IndexedDB). There is no SubScribe server and no account. When you translate or summarize a video, its transcript is sent to OpenRouter and the AI model you chose, using your own API key. Nothing else leaves your browser.

SubScribe itself is free and open source (MIT). AI features run on your own OpenRouter key, and OpenRouter charges per use depending on the model you pick. SubScribe shows the exact cost of every translation and summary.

Only for translation and summaries. Saving transcripts, the library, search and export work without one.

The AI only translates; it never sets timing. SubScribe reads the caption data YouTube's player itself uses, which is precise to the millisecond, and maps every translated sentence back to it. If that data can't be read, it falls back to the transcript panel, which has whole-second timestamps. You can always nudge subtitles with [ and ].

Any video that has captions on YouTube can be translated into 18 languages: Turkish, English, German, French, Spanish, Portuguese (Brazil), Italian, Dutch, Polish, Russian, Ukrainian, Arabic, Persian, Hindi, Indonesian, Japanese, Korean and Simplified Chinese.

Chrome, Edge, Firefox and browsers built on them, with Tampermonkey installed. Safari with Tampermonkey may work but hasn't been tested.

Yes. Each translation can be downloaded as an SRT or VTT subtitle file, and the dashboard exports your whole library — transcripts, translations, summaries, tags and favorites — as a JSON backup you can import later.
